## Практический вывод

Для цели «играть в нативный CoD3 на Windows» первым выбором для проверки
является существующий релиз, а не повторная реализация всех систем.
Наша основа имеет смысл как отдельная реализация на ReXGlue и место для
исследования/исправления SDK. Переключение основы ещё не выполнено.

| Область | Наша основа | CoD3Recomp |
|---|---|---|
| CPU codegen | ReXGlue 0.10.0 | XenonRecomp с локальными изменениями |
| Runtime | ReXGlue SDK | Собственный host/kernel |
| GPU | Официальный Xenos plugin, D3D12 | Собственный D3D11 renderer |
| Меню | Пользователь подтвердил ручной запуск | Заявлено автором; есть релизы и изображения |
| Уровни | Только default.xex; DLL ещё не рекомпилированы | Все 15 DLL связаны в библиотеки, заявлена работа уровней |
| Играбельность | Вылет при вызове кода Saint-Lô | По README/STATUS работает; локально не проверено |

## Что полезно исследовать

- `CoD3Host/modules.cpp`: загрузка DLL, экспортные ordinal, attach/detach,
  выбор таблицы native функций активного уровня. Все уровни используют одну
  базу, поэтому нельзя зарегистрировать их одновременно только по адресу.
- `scripts/recompile_level.ps1`, `CoD3RecompLib/levels/CMakeLists.txt`:
  отдельная генерация и библиотеки уровней, отдельные имена таблиц/helpers.
- `CoD3RecompLib/config/CoD3.toml`: найденные границы, switch tables,
  setjmp/longjmp. Адреса следует независимо проверить по нашему XEX/Ghidra.
- `scripts/patch_recomp.py`, `CoD3Host/coroutines.cpp`: игровой код возобновляет
  coroutine внутри функции, а не только с entrypoint. Их fiber реализация
  полезна как описание проблемы, но не совместима автоматически с ReXGlue.
  Скрипт меняет generated C++; у нас ручное изменение generated code запрещено.
- STATUS и release notes: синхронизация GPU, чтение архивов, teardown,
  сохранения, перезапуск между миссиями и известные ошибки.

Исходный default.xex имеет совпадающие image base и entrypoint, но этого
недостаточно для доказательства полного совпадения бинарника. Сравнение SHA-256
и байтов для каждого переносимого адреса обязательно. Прямое копирование
таблиц XenonRecomp в TOML ReXGlue без адаптации неверно.

## Условия использования

GitHub API на момент проверки возвращает `license: null`; полное дерево
репозитория не содержит общей LICENSE/COPYING, только LICENSE Dear ImGui.

на произвольное использование: [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
Автору сообщений не отправляли.

## Следующая проверка для решения о переходе

Проверить [релиз v0.4.0](https://github.com/FrankHUN88453/CoD3Recomp/releases/tag/v0.4.0)
в отдельной папке с нашими извлечёнными данными, затем первую миссию,
сохранение/загрузку и переход между миссиями. Релиз/host ещё не скачан и не
запущен. Известные ошибки релиза включают графические spikes/glints и отсутствие
оружия/HUD после отладочного spmap внутри уровня. Заявленная работа каждого
уровня не равна подтверждённому безошибочному прохождению всей кампании.
