# Проверки

`./tools/Build.ps1 -Stage Tests`: 3 теста парсера прошли после переноса
временных fixtures в `reports/test-temp` (Windows sandbox Temp не позволял запись).
Проверяются MSB-first версия XEX, усечённый заголовок и недопустимое число
optional headers. Тесты не используют оригинальные игровые материалы.

Полное извлечение: 552 файла, 6 190 037 625 байт, размеры каждого файла
сверены с GDFX directory tree. Signature/hash-tree контейнера не проверялись.
XEX SHA-256 и resource prefixes сохраняются локально в `reports/game-analysis.json`.

Первая codegen в строгом режиме выявила две ошибки. Ghidra headless с
XEXLoaderWV подтверждает инструкции и границы; добавлены только функции
размером 4 и 8 байт. Повторная codegen с `--ignore-stamp`, без `--force`,
завершилась успешно. Это не доказывает полную правильность анализа.

Нативный Debug EXE успешно собран Clang 23.1.3. Первый запуск без GPU загрузил
XEX и зарегистрировал 19 298 функций, затем дошёл до VdInitializeRingBuffer.
Процесс был остановлен после диагностического интервала. Добавлены Xenos GPU
и точный маркер `COD3_ORIGINAL_ENTRY_ENTER`. Последующие реальные запуски
подтвердили этот маркер, GPU pipelines и audio callback. После регистрации
Ghidra-проверенных косвенных targets последний запуск показывает чёрный экран
без FATAL в логе; позднее меню подтверждено пользователем.

Оптимизированная RelWithDebInfo сборка (-O2) проходит native tests
guest_nonlocal_jump и script_fiber_continuations. Проверяются переход через
несколько host frames, независимые ключи, повторный jump, удержание локальных
переменных и раздельное состояние округления FPU двух fibers. Тесты не доказывают
корректность всей игровой coroutine системы. Run-Native -FirstMission передаёт
штатную команду +spmap saint_lo, запускает настоящую миссию и сохраняет отдельный
лог каждого запуска. Ошибки не подавляются, crash dump анализируется LLDB.

2026-10-12 15:13: native-20261012-151011-613.log проходит прежние остановки
duplicate-start и indirect target 890C1950. Windows Computer Use проверил
окно cod3pc.exe из win-amd64-relwithdebinfo: оригинальный лагерь Saint-Lo,
солдаты, оружие от первого лица и компас. Лог продолжает script starts,
resumes и releases без FATAL. Это подтверждает загрузку первого уровня;
пользователь дополнительно подтвердил управление персонажем. Прохождение,
отдельные действия ввода и длительная стабильность ещё не проверены.

Для каждого runtime-сбоя сохранять guest PC, первый неверный вызов, контракт
импорта, стек и сравнение с Xenia. Не делать вывод о меню по созданию окна,
инициализации GPU, таймауту smoke test или наличию EXE. Нужна визуальная
проверка оригинального меню и корректного ввода; кампания проверяется отдельно.
