# Блокеры

## Оригинальное меню

После устранения двух analysis errors и runtime entry 822C27F8 выявлен
следующий незарегистрированный косвенный вызов: 822CAB78.
Проверка Ghidra продолжается; не заменять вызов заглушкой или возвращением
успеха. Runtime abort подтверждён логом и настоящим Windows CRT диалогом.

## Кампания

15 XEX DLL из sp ещё не рекомпилированы и не подключены в module registry.
Первая миссия, NGL resource loader, WBK audio и сохранения не исследованы
до уровня совместимости. Требуется сравнение с оригиналом/Xenia Canary.

## Критерии проверки

Запуск EXE, вход в оригинальный код, GPU/audio init подтверждены. Оригинальный
экран меню, полная загрузка ресурсов и игровой цикл не подтверждены.
Ни один из этих результатов не подменяется демонстрационным экраном.

Внешних блокеров по игровым файлам или установке компилятора сейчас нет.
Следующие работы технические, дополнительная копия игры пока не требуется.
