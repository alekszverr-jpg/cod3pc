## Пройденный блокер: вылет после грузовика

требует новой строгой генерации, сборки и повторения поездки в игре.

Восемь тестов, strict codegen и native build прошли; generated registration
содержит 0x823C1F68. Новый игровой запуск подготовлен для проверки поездки.
Этот результат устраняет отсутствие данной регистрации. Пользователь
подтвердил прохождение поездки и вход в бой в следующем запуске.

## Кампания

Конкретный сбой первого уровня в `cod3pc_006.log` (00:30:28): runtime не нашёл
entrypoint 0x892347A8, затем аварийно остановился на 0x890985E0. Entry точно
совпадает с `saint_lo.dll` из локального inventory, image base 0x89000000.
Этот блокер устранён: DLL рекомпилирована и runtime регистрирует 6071 функцию.
Последующие ошибки 0x00005104, затем 0x00000010 и C0000028 выявили проблемы
необычных coroutine переходов. Последний C0000028 приходит из event-wait
824AB570; его Ghidra-проверенный tail и coroutine адаптер теперь добавлены.
Очистка host continuations после оригинального освобождения 824A5D70
устранила остановку на повторном запуске сценария. Запуск
native-20261012-150633-931.log прошёл дальше и остановился на незарегистрированном
indirect target 890C1950. Ghidra подтвердил отдельный оригинальный blr,
размер 4 байта; добавлен configs/saint_lo_functions.toml. Повторный запуск
native-20261012-151011-613.log в 15:13 визуально подтвердил загрузку лагеря
Saint-Lo с оружием, солдатами и компасом. Этот конкретный вылет устранён.

Остальные 14 XEX DLL из sp ещё не рекомпилированы и не подключены в registry.
Прохождение первой миссии, NGL resource loader, WBK audio и сохранения не исследованы
до уровня совместимости. Требуется сравнение с оригиналом/Xenia Canary.

## Критерии проверки

## Отрисовка травы

Подтверждены растянутые зелёные полосы. Пользователь выбрал сохранить траву
и исправлять рендер. Синхронный GPU memexport не убрал дефект; выполнены
локальные RenderDoc captures. Поправка актуальности динамических vertex buffers
и полный GPU readback не убрали полосы по проверке пользователя. В новых кадрах
найден дефект позиции внутри шейдера травы. Точечная правка однородной координаты
убирает полосы в replay и сохраняет пиксели динамической травы; отдельный GPU
плагин собирается для проверки в живой игре. Причина расхождения с GPU Xbox 360
ещё не установлена; это эксперимент совместимости, не общий фикс Xenos ALU.
На 2026-10-13 новая правка трёх scalar операций восстановила вертикальную форму
травы в проверенных ракурсах возле Хаксли; пользователь подтвердил результат.
Дефект длинных полос и наклонных лент в этих ракурсах устранён. Коррекция
включена в обычный Windows RelWithDebInfo запуск. Это точечная совместимость
шейдера; общий аппаратный механизм расхождения пока не доказан.
Подробности: GPU_RENDERING.md. Во время продолжения игры обнаружен новый
target 82498510; его оригинальная функция проверена Ghidra и включена в codegen.
