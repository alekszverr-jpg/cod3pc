Текущий запуск native-20261021-092702-382.log сообщает Realtek, 2 канала,
48000 Hz, submitting 2 ch. Это другой endpoint, чем прежняя 8-канальная
Logitech; нельзя приписывать одинаковую причину всем предыдущим наблюдениям.

В нашем pinned SDK StereoFold уже исключает LFE (lfe=0), тогда как SurroundMix
по умолчанию пропускает его (lfe=1). Поэтому чужой приём с отключением LFE
для многоканального выхода не изменит текущий стереовыход и не является
универсальным исправлением неправильного направления. Нужен отдельно
воспроизводимый неподвижный источник и сведения об используемом устройстве.

В XmaContext::Work нашего SDK присутствует проверка output_rb.empty(),
безусловно очищающая output_buffer_valid, в том числе после прохода без
записанного PCM. Внешний patch 0061 ограничивает это фактом записи и
переполнения кольца. Совпадение кода подтверждено; повтор концов звуков в
нашем текущем запуске не измерен. Это отдельный кандидат для проверки XMA,
не объяснение панорамы. Patch 0061 не применён; pacing, SDK ABI и audio drain
при Runtime restart необходимо проверять отдельно перед любым переносом.

native-20261013-130703-196.1.log: endpoint Logitech PRO X Wireless Gaming
Headset сообщает 8 каналов / 48000 Hz; SDK отправляет 6 каналов. Ранее endpoint
Realtek сообщал 2 канала. Настройки виртуального surround гарнитуры не проверены.

Проверенный pinned SDL driver выбирает stereo fold для endpoint <=2 каналов;
для большего количества передаёт 6 каналов в SDL AudioStream, который выполняет
последующее преобразование к endpoint. conversion.h сохраняет guest channel
order FL/FR/FC/LFE/BL/BR в six-channel output; default SurroundMix unity.
Таким образом, восьмиканальный endpoint — конкретная развилка для сравнения,
но сам по себе не доказывает ошибку каналов.

Следующая проверка: один неподвижный источник, повороты камеры по четырём
направлениям, сопоставление front/center/rear каналов и конечного endpoint;
сравнить с двухканальным выходом и оригиналом. Проверить также attenuation
и guest mix до host conversion. Не менять слепо местами каналы и не повышать
общую громкость в качестве исправления позиционирования.
