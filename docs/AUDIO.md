# Диагностика пространственного звука

2026-10-13: пользователь сообщает, что источники временами слишком тихие
или слышны с неправильной стороны. Исправление и точная причина не установлены.

native-20261013-130703-196.1.log: endpoint Logitech PRO X Wireless Gaming
Headset сообщает 8 каналов / 48000 Hz; SDK отправляет 6 каналов. Ранее endpoint
Realtek сообщал 2 канала. Настройки виртуального surround гарнитуры не проверены.

Проверенный pinned SDL driver выбирает stereo fold для endpoint <=2 каналов;
для большего количества передаёт 6 каналов в SDL AudioStream, который выполняет
последующее преобразование к endpoint. conversion.h сохраняет guest channel
order FL/FR/FC/LFE/BL/BR в six-channel output; default SurroundMix unity.
Таким образом, восьмиканальный endpoint — конкретная развилка для сравнения,
но сам по себе не доказывает ошибку каналов.

Следующая проверка: один неподвижный источник, повороты камеры по четырём
направлениям, сопоставление front/center/rear каналов и конечного endpoint;
сравнить с двухканальным выходом и оригиналом. Проверить также attenuation
и guest mix до host conversion. Не менять слепо местами каналы и не повышать
общую громкость в качестве исправления позиционирования.
